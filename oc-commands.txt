Quick one-liner (interactive)

Find app-ids that own 2+ namespaces on the cluster you're logged into:

oc get namespaces -o jsonpath='{range .items[*]}{.metadata.name}{"\n"}{end}' \
  | grep -E '^app[0-9]+-' \
  | sed -E 's/^(app[0-9]+)-.*/\1/' \
  | sort | uniq -c \
  | awk '$1 >= 2 {print $2" -> "$1" namespaces"}'

What each stage does:

oc get namespaces ... jsonpath → prints one namespace name per line.
grep -E '^app[0-9]+-' → keep only namespaces matching your app-id pattern.
sed -E 's/^(app[0-9]+)-.*/\1/' → strip everything after the app-id → leaves just app123445679.
sort | uniq -c → count how many namespaces per app-id.
awk '$1 >= 2' → keep only app-ids with 2 or more.
See the actual namespace names grouped per app-id

oc get namespaces -o jsonpath='{range .items[*]}{.metadata.name}{"\n"}{end}' \
  | grep -E '^app[0-9]+-' \
  | awk -F'-' '{print $1"\t"$0}' \
  | sort \
  | awk -F'\t' '{c[$1]++; list[$1]=list[$1]" "$2} END{for(a in c) if(c[a]>=2) print a" ("c[a]"):"list[a]}'
